legacy 口径提示（2026-11-14 补注）：本报告的偏航数字使用旧公式 2·atan2(qz,qw)，奖励分项是在 env.step() 之后重算的（参考状态已推进，加权和与实际 reward 平均差 0.107），速度项分布也因此不可用。修正后的指标与全部重跑结果见仓库根目录 results/summary_table.md，方法与口径说明见 docs/IMPROVEMENTS.md。

01复现了什么，没复现什么

论文的系统由四段组成：① 把真实狗的动作捕捉重定向到 Laikago（IK）；② 用 PPO 在仿真中模仿参考动作学习策略； ③ 训练时随机化动力学参数，并把参数编码进潜在向量；④ 在真实机器人上用 AWR 在潜在空间里做在线适应。

05与论文 Table V 的对比

论文 Table V 报告的是归一化回报（每个回合内 0 = 最差、1 = 理论最优，3 个随机种子 × 5 回合）。 仓库没有实现这套归一化，本次用每步奖励作为近似——因为 5 个分项各自都是 0–1 的指数型奖励， 每步奖励天然落在 0–1，且其上限 1 恰好等于「完美跟踪」，与归一化回报的尺度可比，但不是严格等价。

差异从哪来（逐项可解释）：
  • Dog Pace 0.750 vs 0.820（−8.6%）：关节跟踪误差 0.065 rad、根位置误差 2.4 cm 都已接近奖励尺度允许的残差； 损失主要来自关节速度分项 0.016 与根姿态 0.93 的边缘损失，属于策略本身的稳态残差，而非评测口径错误。
  • Dog Spin 0.638 vs 0.839（−24%）：根姿态分项只有 0.030。逐帧数据显示偏航误差从 0.06 rad 单调累积到 1.0 rad （均值 0.80 rad）——参考片段每个 0.75 s 周期转 1.734 rad（2.31 rad/s），策略实际转速略低（约差 0.05 rad/s）， 20 s 连续旋转后累积近 1 rad。姿态特征里不含根位置、也不含累计转角，策略无法校正这类漂移，这是模仿框架的固有性质。
  • 口径差异：论文是 3 个种子训练出的策略各评 5 回合并取均值±标准差，且回合起点在参考动作上随机采样； 本次是单策略、固定从 t=0 起的确定性回合，因此没有误差棒，多次运行结果逐帧一致。
  • 仿真器版本：PyBullet 3.2.0（原环境）而非 requirements 指定的 2.7.3，接触求解与电机模型会有细微差别。

07结论

  • 代码可跑通：官方仓库在 Windows + CPU + MS-MPI 上无需改一行代码即可训练与评估； 本次只新增脚本，并全部放在新目录里。
  • 论文数据可复现：10 段参考动作的运动学特征（时长、速度、根高）与论文描述一致； 官方预训练策略在仿真中跑满 19.8 s 不跌落，Dog Pace 达到论文仿真归一化回报的 91%，Dog Spin 76%。
  • 训练可复现但预算不可比：管线、超参、奖励权重、观测结构（历史 3 帧 + t+1/2/10/30 四帧目标）逐项对齐论文， 但 2e8 采样 × 3 种子在 CPU 上不可行，本次 3e5 只够验证流程。
  • 不可复现的部分：IK 重定向工具、潜在编码器与 AWR 自适应、真机实验——上游未发布，本机无硬件。
