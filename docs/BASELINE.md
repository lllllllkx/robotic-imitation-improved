## 2. 本阶段的结论口径（不得改写为更强表述）

1. **周期朝向重锚定改变了偏航误差的参考系，而非跟踪能力。** 周期对齐口径 0.2081 → 0.0627 rad（−69.9%），但同一轨迹固定参考系重建为 1.4503 ± 0.1021 rad，累计参考系转动 −3.03 rad（26–27 次周期事件）。该量统一称"固定参考系等价误差（同轨迹事后重建）"，不称"真实跟踪误差"。
2. **速度奖励 v2 改变的是奖励数值分布。** 速度项均值 2.6e-3 → 0.191，加权贡献 0.02% → 2.6%，权重和仍为 1；同轨迹行为指标逐位不变。结论止于"奖励信号饱和程度降低"，不写"策略性能提升"。
3. **评估与日志可靠性得到改进。** 奖励分项与跟踪误差同在 `task.reward()` 快照、任务 RNG 按 seed 钉住、`info["terminated"]` 优先判定终止、分项自洽与恒等审计（≤ 2.22e-15 rad）、44 例单测。
